#  Sistema de Controle de Chaves

Sistema web desenvolvido para gerenciamento e controle de chaves,
usuários, autorizações e histórico de movimentações.

##  Sobre o projeto

O sistema foi desenvolvido para digitalizar o controle de retirada
e devolução de chaves, permitindo maior organização, rastreabilidade
e controle das movimentações.

##  Funcionalidades

- Cadastro de chaves
- Cadastro de usuários
- Cadastro de pessoas autorizadas
- Retirada de chaves
- Devolução de chaves
- Controle de status das chaves
- Histórico de movimentações
- Registro de observações
- Controle de acesso por perfil
- Painel administrativo
- Painel para usuários
- Registro de horário de retirada e devolução

##  Tecnologias

- PHP
- MySQL / MariaDB
- HTML5
- CSS3
- JavaScript
- XAMPP
- Git
- GitHub

##  Controle de acesso

O sistema possui diferentes níveis de acesso,
permitindo separar as funcionalidades administrativas
das operações realizadas pelos usuários.

## 📊 Histórico

Cada movimentação pode registrar:

- Chave utilizada
- Pessoa autorizada
- Responsável pela entrega
- Horário de retirada
- Responsável pela devolução
- Horário de devolução
- Observações

##  Como executar

### Requisitos

- XAMPP
- PHP
- MySQL/MariaDB
- Navegador

### Instalação

1. Clone o repositório
2. Coloque o projeto na pasta `htdocs`
3. Crie o banco de dados
4. Configure a conexão
5. Inicie Apache e MySQL pelo XAMPP
6. Acesse o projeto pelo navegador
